# 阿斯兰战舰世界经典版镜像

这是「窝窝斯坐牢小助手」使用的备用安装包仓库，模组包由 [Aslain](https://aslain.com/) 制作。安装包保留官网原始文件，SHA-256 见各发行版说明。

- **安装包**：到 [GitCode 发行版](https://gitcode.com/REREREGO/aslain_versions/releases) 下载，不需要登录。
- **蓝奏云备用**：[下载目录](https://wwbcm.lanzouq.com/b01i60xlde)，提取码 `6fpw`。目录由维护者手动上传。
- **版本查询**：助手读取 [Gitee 版本清单](https://gitee.com/rererergo/aslain_versions/raw/master/catalog.json)，核验签名后选择与游戏版本匹配的安装包。
- **助手与说明**：[wows-aslain-assistant](https://github.com/REREREGO/wows-aslain-assistant)。

安装器中的部分模组仍需连接 Aslain 下载。请匹配自己的游戏版本，安装前退出游戏。

保留上限暂定两年；空间不足时优先清理旧包，同时保留仍需支持的游戏版本。自动同步失败时不会生成假的新版本；三天没有成功同步后清单过期，助手会尝试官网。
