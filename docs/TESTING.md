# 测试

在 Windows PowerShell 中构建后运行：

```powershell
.\build.ps1 -OutputDirectory build
.\build\AslainAssistant.Tests.exe
.\build\AslainAssistant.UiTests.exe
.\tests\MirrorRetention.Tests.ps1
```

业务测试使用独立目录和模拟安装器，不会安装阿斯兰，也不会改动玩家的客户端配置。界面测试使用独立配置，在后台创建测试窗口，执行时先退出正常运行的助手。

单实例测试需要没有运行中的助手，会启动 8 个使用独立配置的后台进程，检查只剩一个实例及其退出协议：

```powershell
.\build\AslainAssistant.InstanceTests.exe
```

新增测试先在旧实现上复现了问题：助手更新收到响应头后，数据流若不再返回且忽略取消信号，取消操作无法结束下载。1.0.2 将两类更新共用同一套有大小限制、闲置超时和取消保护的流读取逻辑；断流、损坏数据、重定向和备用源切换均有回归覆盖。

实际验证没有启动阿斯兰安装器，没有安装或改动游戏模组，也没有关闭或重启游戏。安装成功与失败分支由独立目录和模拟安装器覆盖，不能据此保证所有第三方插件在所有游戏版本中兼容。

## 可选联网检查

```powershell
# 读取助手发布清单并验证签名，不下载或运行安装器
.\build\AslainAssistant.Tests.exe --self-check-live

# 下载并校验已发布的助手安装器，不执行安装器
.\build\AslainAssistant.Tests.exe --self-live

# 回归测试、官网版本查询与安装包校验；只读取本机游戏信息
.\build\AslainAssistant.Tests.exe --live --download
```

联网测试受服务端可用性影响，应与本地测试结果分别记录。自更新测试产生的下载文件保存在 `artifacts`，不会自动安装。
